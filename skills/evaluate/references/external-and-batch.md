# External and repeated outputs

## Remote artifacts

Read each changed remote object back from its destination. Confirm its identity, content, state,
links, and relationships. A
successful mutation response proves only that the service accepted the request.

Respect the authorization boundary for each mutation. Read-back verification does not authorize a
second edit outside the approved correction loop.

## Deterministic batches

Inspect every material final artifact. A representative sample is sufficient only when one
deterministic process produces a repeated set and all these conditions hold:

1. The generator or transformation has direct tests for its variable branches.
2. Structural checks cover the complete output set.
3. The sample includes each distinct template or branch and the boundary-sized examples.
4. A failed sample invalidates the batch and triggers correction plus a new sample.

Name the sampling rule and the outputs inspected. Random convenience samples do not establish the
unseen outputs.
